## Background Removal & Cleanup

Tools dedicated to extracting subjects, removing backgrounds, and cleaning up unwanted objects from photos.

* [Remove.photos](https://remove.photos) - A powerful, fully automated cloud AI tool for instant background removal, transparent background creation, and object cleanup with zero local processing required.
* [Photoroom](https://www.photoroom.com/) - App and web-based tool for removing backgrounds and creating product images.
* [Clipdrop](https://clipdrop.co/) - An ecosystem of apps, plugins, and resources for all creators to remove backgrounds and clean up images.
* [Cleanup.pictures](https://cleanup.pictures/) - Remove objects, people, text, and defects from any picture.
* [Zubware Background Remover](https://www.zubware.com/background-remover) - Free browser-based tool for removing photo backgrounds and exporting cutouts.

## Image Generation

Tools that generate images from text prompts using advanced diffusion models.

* [Midjourney](https://www.midjourney.com/) - An independent research lab exploring new mediums of thought and expanding the imaginative powers of the human species.
* [DALL·E 3](https://openai.com/dall-e-3) - OpenAI's premier image generation model integrated into ChatGPT.
* [Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) - A browser interface for Stable Diffusion.

## Upscaling & Enhancement

Tools to enlarge images without losing quality, colorize old photos, and enhance details.

* [Upscayl](https://upscayl.org/) - Free and open-source AI image upscaler built with Linux-first philosophy (but works everywhere).
* [Magnific AI](https://magnific.ai/) - A highly advanced AI image upscaler and enhancer.
* [Topaz Photo AI](https://www.topazlabs.com/topaz-photo-ai) - Desktop software that sharpens, removes noise, and increases the resolution of your photos.
